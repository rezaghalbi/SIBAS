# Visual Identity & Design System - SIBAS

## 1. Palet Warna Utama
- Primary (Hijau Tua): `#005746` (Gunakan pada AppBar, Tombol Utama, Header)
- Secondary (Hijau Daun): `#16865D` (Gunakan pada Aksesori, Status Disetujui, Card Accent)
- Accent (Hijau Muda): `#9BD84A` (Gunakan pada Highlight, Indicator, Floating Action)
- Background: `#FFFFFF` / Neutral Light `#F8F9FA`
- Danger/Reject: `#D32F2F`

## 2. Aset Logo & Branding
- Path File Logo Utama: `assets/images/logo_sibas.png`
- Penggunaan: Tampilkan logo di Halaman Login/Register dan Header Dashboard.
- Typography: Gunakan Google Fonts (Poppins / Inter) dengan hirarki font yang jelas.
